# Aster Lang समुदाय

> Policy-as-Code को अपनी मातृभाषा में लाने में मदद करें।

## Lexicon पारिस्थितिकी तंत्र क्या है?

Aster Lang का CNL कंपाइलर **डिज़ाइन से भाषा-अज्ञेयवादी** है। हर समर्थित भाषा एक **lexicon प्लगइन** के रूप में आती है — एक छोटा JSON + Java पैकेज जो कीवर्ड अनुवाद और syntax नियम परिभाषित करता है।

इसका मतलब है कि आप:

- ~75 कीवर्ड के साथ Aster को अपनी भाषा में अनुवाद कर सकते हैं
- अपना lexicon एक maven artifact के रूप में प्रकाशित कर सकते हैं
- एक Aster Language Steward बन सकते हैं
